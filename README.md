## About Tennis Umpire
Tennis Umpire is a simple native Android application that brings an easy to use interface to referee tennis matches. So that tennis entusiasts and not-professional tennis chair umpires have access to a great and free software to referee matches.

## Features goals
All these features are currently in progress of being implemented:
- Live result matches managing with the ability to modify each match rules.
- Create players profiles and use them in the matches.
- Save matches, results and players.
- Visualize statistics for each match, result, player, etc.
- Light/Dark mode.
- Responsive layout adapted for landscape or portrait use.
- Multilanguage.
- Local database to store all players, results and matches data.

## Technologies and Languages
- Android
- Jetpack Compose
- Kotlin
- SQL
- SQLDelight (I will probably use this for the local Database)
For this project, I wanted to learn the latest things for Android. So I'm using the latest versions even if experimental of all the Android dependencies. Such as Material 3, Navigation 3 and more.
